## 2026-03-03 - Debounce Autocomplete API Requests & Isolate Tests from Broken Dependencies
**Learning:** `SearchDestinationPlace` fired an unthrottled Google Places Autocomplete HTTP request on every single keystroke in `TextField(onChanged)`, generating unnecessary network traffic, consuming API quota, risking out-of-order response race conditions, and leaking `TextEditingController`s upon exit. Furthermore, compiling tests that transitively import `main.dart` pulls in `register_screen.dart` which imports `rounded_loading_button: 2.1.0` (incompatible with modern Flutter SDKs).
**Action:** Always debounce text search / autocomplete inputs by 300-400ms and properly dispose timers and controllers in `dispose()`. When writing unit or widget tests for screens in `uber_users_app`, avoid unnecessary imports of `main.dart` to prevent triggering compilation errors from obsolete dependencies like `rounded_loading_button`.
